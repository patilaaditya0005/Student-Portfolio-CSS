# Aaditya Patil — Portfolio

A personal portfolio built with simple HTML and one shared CSS file.

## Pages
- `index.html` — Home
- `about.html` — About
- `education.html` — Education
- `skills.html` — Skills
- `projects.html` — Projects and the single video demo
- `contact.html` — Contact

## Files
- `common.css` — Shared black-and-white design, responsive layout, and animations for every page
- `assets/` — Portrait photos
- `soil1.jpg`, `soil2.jpg`, `soil3.jpg`, `soil4.jpg` — Project images
- `demo.mp4` — Soil Advisory System video demonstration

## Run locally
Open `index.html` in a browser. No framework or build tools are required.

## Built with
HTML and CSS.
